Procurementক্রয়

Request → approval → purchase order → LC (imports) → receipt → inventory → gate pass.অনুরোধ → অনুমোদন → ক্রয়াদেশ → এলসি (আমদানি) → গ্রহণ → মজুদ → গেট পাস।

The approval chain, thresholds and required fields for procurement, LC, PO and gate pass are not yet defined by the client.ক্রয়, এলসি, পিও ও গেট পাসের অনুমোদন ধাপ, সীমা ও প্রয়োজনীয় ঘর ক্লায়েন্ট এখনও নির্ধারণ করেননি।

The prototype assumes: Principal → District (review) → Ministry (above ৳ 3 lakh).প্রোটোটাইপে ধরা হয়েছে: অধ্যক্ষ → জেলা (পর্যালোচনা) → মন্ত্রণালয় (৩ লাখ টাকার বেশি)। TBD — Requires Client Confirmationনির্ধারিত হবে — ক্লায়েন্টের নিশ্চিতকরণ প্রয়োজন
