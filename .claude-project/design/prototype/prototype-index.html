End-to-end flows (A–J)এন্ড-টু-এন্ড ফ্লো (A–J)

Each flow keeps its progress across pages. Use “Reset demo data” to start again.প্রতিটি ফ্লো পাতা জুড়ে অগ্রগতি সংরক্ষণ করে। নতুন করে শুরু করতে “ডেমো তথ্য রিসেট” ব্যবহার করুন।

  1. A
    Candidate → Studentপ্রার্থী → শিক্ষার্থী

    1. Admissions → 2. Apply → 3. Pay fee → result → final admission → 4. Student ID & dashboard

  2. B
    Attendance → aggregate viewsহাজিরা → সমষ্টিগত দৃশ্য

    1. Teacher submits → 2. Institution → 3. District → 4. Division → 5. Ministry

  3. C
    Result entry → publish → studentফলাফল এন্ট্রি → প্রকাশ → শিক্ষার্থী

    1. Teacher enters → 2. Principal validates & publishes → 3. Student sees result

  4. D
    Service request lifecycleসেবা আবেদনের ধাপ

    1. Student submits → 2. Principal returns → 3. Student corrects → 4. Approve → complete

  5. E
    Budget → expenses → utilisationবাজেট → ব্যয় → ব্যবহার

    1. Ministry allocates → 2. Institution records expense → 3. Utilisation report

  6. F
    Asset lifecycleসম্পদের ধাপ

    1. Ministry allocates → 2. Assign → transfer/return → damaged/lost → history

  7. G
    Procurement → gate passক্রয় → গেট পাস

    1. Request → 2. Approve → 3. PO → LC → receive → gate pass

  8. H
    Teacher leaveশিক্ষকের ছুটি

    1. Apply → 2. Principal approves → 3. Balance updated

  9. I
    Certificate → alumniসনদ → প্রাক্তন শিক্ষার্থী

    1. Graduate applies → 2. Issue & mark alumni → 3. Alumni portal

  10. J
    Professional licence → verificationপেশাগত লাইসেন্স → যাচাই

    1. Apply → 2. Review & issue → 3. Organisation registers → 4. Pay & verify
