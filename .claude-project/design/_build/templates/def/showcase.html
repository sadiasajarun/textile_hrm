How to review

  1. Start from 01 Public Home. It is a public website, so no sign-in is needed.
  2. Choose Login. Demo accounts route by role (password demo1234): ministry.admin, division.ctg, district.ctg, saiful.islam (two workspaces), arif.hossain, mim.akter, inactive.user.
  3. Inside the app, the dashed Prototype Role Preview menu jumps between roles. It exists only for review. In production, roles are assigned and never chosen.
  4. Ministry dashboard: drill National → Chattogram Division → Chattogram District → Karnaphuli Textile Institute → Institution 360°.
  5. Switch বাংলা | English on any page. Navigation, titles, buttons, KPI labels, statuses and table headings change.
  6. The bottom-right bar switches D/E/F for the same screen.
